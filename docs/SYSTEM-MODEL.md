## 示例（另一个项目，外卖下单系统）

**契约**：入口=选商品/下单/取消；出口=订单状态变化+通知；不做=支付风控。

**状态**：待支付 → 已支付 → 配送中 → 完成；非法组合=「已取消」还在「配送中」。

**数据**：订单存在数据库；购物车存在浏览器；「临时优惠券」谁清？→ 未知。

**失败**：支付回调超时 → 订单卡在待支付 → 需要轮询补偿；用户看到「支付处理中」。

**不变量**：一个订单只能支付一次；库存不能为负；取消后不能发货。

**未知**：优惠券过期后订单里的价格会不会变。
