## Bug

- [ ] **B1** 暂停后切会话：高亮卡死，或直接朗读新会话内容
  - 现象：暂停 → 切到其他会话 → 黄色高亮停在原地不动；有时直接开始读新会话
  - 期望：继续时回到原会话原位置并恢复高亮；或提示「回原会话才能继续」
  - 验收：暂停后切会话，不应有任何声音；切回来点继续，从原句恢复

  - 来源：2026-11-22

  - 期望：开口的同时高亮出现在第一句，并跟随滚动
  - 验收：自动朗读开始后 1 秒内，高亮可见且在当前句
  - 初判：与 B1 同源——`scopeEl` / 高亮缓存的生命周期没跟着回合走
