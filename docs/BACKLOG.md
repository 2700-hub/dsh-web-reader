## Bug

- [ ] **B1** 暂停后切会话：高亮卡死，或直接朗读新会话内容
  - 现象：暂停 → 切到其他会话 → 黄色高亮停在原地不动；有时直接开始读新会话
  - 期望：继续时回到原会话原位置并恢复高亮；或提示「回原会话才能继续」
  - 验收：暂停后切会话，不应有任何声音；切回来点继续，从原句恢复
  - 初判：`state.scopeEl` 指向已被移除的旧节点；`paused` 状态跨会话存活
  - 来源：2026-11-22

- [ ] **B2** 新一轮对话自动朗读时，高亮和视野没跟上
  - 现象：已经开始读了，但高亮不动 / 页面没滚过去
  - 期望：开口的同时高亮出现在第一句，并跟随滚动
  - 验收：自动朗读开始后 1 秒内，高亮可见且在当前句
  - 初判：与 B1 同源——`scopeEl` / 高亮缓存的生命周期没跟着回合走
  - 来源：2026-11-22

- [ ] **B3** 重新生成同一条回复时可能漏读（未验证）
  - 验收：点重新生成，应再读一次；日志出现新的 `ready`
  - 初判：turn 号复用会导致 `autoSeen` 误判
  - 来源：2026-11-22 未知清单

- [ ] **B4** 多标签页同时打开时可能抢音频（未验证）
  - 验收：两个标签页各读一条，不应互相打断 / 双声
  - 初判：每个页面一个脚本实例，没有跨页协调
  - 来源：2026-11-22 未知清单

- [ ] **B5** 暂停后滚动屏幕，高亮框停在视野中央挡字
  - 现象：暂停 + 滚动，黄色框固定不动（`position: fixed`，锚在视口坐标而不是文字）
  - 期望：高亮始终贴着那句话；或者暂停滚动时干脆隐藏
  - 验收：暂停后滚动，高亮跟着文字走，不盖住正在读的句子
  - 初判：不是 bug，是设计选择。修法是"滚动时重算高亮位置"，不是重构
  - 来源：2026-11-23

- [ ] **B6** 多个代码块里有相同词语时，高亮在几块之间闪
  - 现象：同样的词在几个代码块出现，高亮按"全文里找得到的第一处"跳
  - 期望：跟着阅读顺序单调前进，不回头
  - 验收：出现重复词时，高亮不往回跳
  - 初判：`highlightChar` 找不到时回退到全文开头（第二次 `indexOf`），这是跳的原因
  - 备选：代码块整块高亮，不做逐字
  - 来源：2026-11-23

- [ ] **B7** ThoughtDAG 画布适配不好：文本被断成几段、没有自动朗读
  - 现象：识别不出全文，读完一段要手动点下一段；新内容不自动读
  - 期望：一次读完整段；画布里也能连续读
  - 初判：通用模式靠 `genericScopeAt` 找容器，粒度不稳；自动朗读只认 `data-chat-turn`
  - 来源：2026-11-23
